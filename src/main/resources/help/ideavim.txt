*ideavim.txt*                                                        *ideavim*

                               IDEAVIM COMMANDS

This file lists the commands that IdeaVim implements. Type ":help" followed by
a subject to jump to it, for example:

    :help x         Normal mode command "x"
    :help v_d       Visual mode command "d"
    :help i_CTRL-W  Insert mode command CTRL-W
    :help c_CTRL-R  Command-line editing command CTRL-R
    :help :s        Ex command ":s"

Contents:
1. Insert mode                                                |ideavim-insert|
2. Normal and Operator-pending mode                           |ideavim-normal|
3. Visual and Select mode                                     |ideavim-visual|
4. Command-line editing                                      |ideavim-cmdline|
5. Ex commands                                                    |ideavim-ex|

==============================================================================
1. Insert mode                                                *ideavim-insert*

                                             *i_CTRL-@* *i_<C-S-2>* *i_CTRL-2*
<C-@> <C-S-2> <C-2>     In Insert mode, insert the previously inserted text
                        and stop inserting.

                                               *i_CTRL-[* *i_CTRL-C* *i_<Esc>*
<C-[> <C-C> <Esc>       Leave Insert mode and return to Normal mode.

                                                             *i_CTRL-\_CTRL-N*
<C-\><C-N>              Go to Normal mode from any mode, abandoning any
                        pending command.

                                                                    *i_CTRL-^*
<C-^>                   In Insert mode, toggle the use of typed language
                        mappings (:lmap) by switching 'iminsert' between 0 and
                        1.

                                                                    *i_CTRL-A*
<C-A>                   In Insert mode, insert the previously inserted text.

                                                                    *i_CTRL-D*
<C-D>                   In Insert mode, delete one 'shiftwidth' of indent at
                        the start of the current line.

                                                                    *i_CTRL-E*
<C-E>                   In Insert mode, insert the character found below the
                        cursor.

<C-E>                   With a completion popup open, close the popup and keep
                        the text typed so far.

                                                                   *i_<C-End>*
<C-End>                 In Insert mode, move the cursor to the end of line
                        [count], default the end of the last line.

                                                                    *i_CTRL-F*
<C-F>                   After CTRL-X in Insert mode, complete the file name
                        before the cursor using a completion popup.

<C-F>                   With a CTRL-X completion popup open, select the next
                        matching file name.

                                                                  *i_CTRL-G_u*
<C-G>u                  In Insert mode, close the current undo step and start
                        a new one.

                                                           *i_CTRL-H* *i_<BS>*
<C-H> <BS>              In Insert mode, delete the character before the
                        cursor. In Replace mode, restore the original
                        character.

                                                                  *i_<C-Home>*
<C-Home>                In Insert mode, move the cursor to the start of line
                        [count], default the first line.

                                                                    *i_CTRL-K*
<C-K>                   In Insert mode, enter digraph {char1}{char2}.

                                                                    *i_CTRL-L*
<C-L>                   After CTRL-X in Insert mode, complete the whole line
                        from matching lines in the buffer using a completion
                        popup.

<C-L>                   With a CTRL-X completion popup open, select the next
                        matching whole line.

                                                    *i_<C-Left>* *i_<C-kLeft>*
<C-Left> <C-kLeft>      In Insert mode, move the cursor [count] words
                        backward.

                                                                    *i_CTRL-N*
<C-N>                   In Insert mode, invoke the IDE action that <C-N> is
                        bound to in the IDE keymap, e.g. to move down in a
                        completion popup.

<C-N>                   With a completion popup open, select the next item.

                                                                    *i_CTRL-O*
<C-O>                   In Insert mode, execute one Normal mode command and
                        then return to Insert mode.

                                                                    *i_CTRL-P*
<C-P>                   In Insert mode, invoke the IDE action that <C-P> is
                        bound to in the IDE keymap, e.g. to move up in a
                        completion popup.

<C-P>                   With a completion popup open, select the previous
                        item.

                                                              *i_<C-PageDown>*
<C-PageDown>            In Insert mode, go to the next editor tab, wrapping
                        around from the last to the first, without leaving
                        Insert mode.

                                                                *i_<C-PageUp>*
<C-PageUp>              In Insert mode, go to the previous editor tab,
                        wrapping around from the first to the last, without
                        leaving Insert mode.

                                                                    *i_CTRL-R*
<C-R>                   In Insert mode, insert the contents of {register}.
                        With = as the register, evaluate an expression and
                        insert the result.

                                                  *i_<C-Right>* *i_<C-kRight>*
<C-Right> <C-kRight>    In Insert mode, move the cursor [count] words forward.

                                                                    *i_CTRL-T*
<C-T>                   In Insert mode, insert one 'shiftwidth' of indent at
                        the start of the current line.

                                                                    *i_CTRL-U*
<C-U>                   In Insert mode, delete all entered text before the
                        cursor in the current line, or the indented text if
                        none was entered.

                                                         *i_CTRL-V* *i_CTRL-Q*
<C-V> <C-Q>             In Insert mode, insert the next non-digit character
                        literally, or a character by its decimal, octal or hex
                        code.

                                                                    *i_CTRL-W*
<C-W>                   In Insert mode, delete the word before the cursor.

                                                                    *i_CTRL-X*
<C-X>                   In Insert mode, start CTRL-X completion; follow with
                        CTRL-L for whole lines or CTRL-F for file names.

                                                                    *i_CTRL-Y*
<C-Y>                   In Insert mode, insert the character found above the
                        cursor.

<C-Y>                   With a completion popup open, accept the selected
                        item.

                                                *i_<CR>* *i_CTRL-M* *i_CTRL-J*
<CR> <C-M> <C-J>        In Insert mode, begin a new line.

                                                                     *i_<Del>*
<Del>                   In Insert mode, delete the character under the cursor
                        using the IDE's Delete action.

                                                        *i_<Down>* *i_<kDown>*
<Down> <kDown>          In Insert mode, move the cursor one line down using
                        the IDE's caret action, starting a new undo step.

                                                                     *i_<End>*
<End>                   In Insert mode, move the cursor past the last
                        character of the line.

                                                                    *i_<Home>*
<Home>                  In Insert mode, move the cursor to the first character
                        of the line.

                                                                  *i_<Insert>*
<Insert>                Toggle between Insert and Replace mode.

                                                        *i_<Left>* *i_<kLeft>*
<Left> <kLeft>          In Insert mode, move the cursor one character to the
                        left. Wrap to the previous line if 'whichwrap'
                        contains [.

                                                                *i_<PageDown>*
<PageDown>              In Insert mode, scroll the window [count] pages
                        forwards (downwards) in the buffer.

                                                                  *i_<PageUp>*
<PageUp>                In Insert mode, scroll the window [count] pages
                        backwards (upwards) in the buffer.

                                                      *i_<Right>* *i_<kRight>*
<Right> <kRight>        In Insert mode, move the cursor one character to the
                        right. Wrap to the next line if 'whichwrap' contains
                        ].

                                                                  *i_<S-Down>*
<S-Down>                If 'keymodel' contains startsel (or continues the
                        current selection), start or extend a selection
                        [count] lines down. Otherwise scroll [count] pages
                        forward.

                                                                   *i_<S-End>*
<S-End>                 Move to the end of the line, [count] - 1 lines
                        downward. If 'keymodel' contains startsel, start or
                        extend a selection.

                                                                  *i_<S-Home>*
<S-Home>                Move to the first character of the line. If 'keymodel'
                        contains startsel, start or extend a selection.

                                                                  *i_<S-Left>*
<S-Left>                Move [count] words backward. If 'keymodel' contains
                        startsel, start or extend a selection [count]
                        characters to the left instead.

                                                                 *i_<S-Right>*
<S-Right>               Move [count] words forward. If 'keymodel' contains
                        startsel, start or extend a selection [count]
                        characters to the right instead.

                                                                    *i_<S-Up>*
<S-Up>                  If 'keymodel' contains startsel (or continues the
                        current selection), start or extend a selection
                        [count] lines up. Otherwise scroll [count] pages
                        backward.

                                                          *i_<Tab>* *i_CTRL-I*
<Tab> <C-I>             In Insert mode, insert a tab or the equivalent spaces
                        using the IDE's Tab action.

                                                            *i_<Up>* *i_<kUp>*
<Up> <kUp>              In Insert mode, move the cursor one line up using the
                        IDE's caret action, starting a new undo step.

2. Normal and Operator-pending mode                           *ideavim-normal*

                                                                           *!*
!                       Start a command line to filter the lines moved over by
                        {motion} through an external {filter} program.

                                                                           *#*
#                       Search backward for the [count]'th occurrence of the
                        whole word under or after the cursor.

                                                                           *$*
$                       Move to the end of the line, [count] - 1 lines
                        downward.

$                       As an operator motion, move to the end of the line,
                        [count] - 1 lines downward. The end-of-line character
                        is not included.

                                                                           *%*
%                       Jump to the matching bracket, brace or parenthesis of
                        the one under or after the cursor. With [count], go to
                        [count] percent of the file (linewise).

                                                                           *&*
&                       Repeat the last :substitute on the current line,
                        without its flags.

                                                                           *'*
'                       Jump to the first non-blank character of the line
                        containing mark {mark}.

                                                                           *(*
(                       Move [count] sentences backward.

                                                                           *)*
)                       Move [count] sentences forward.

                                                                        *star*
*                       Search forward for the [count]'th occurrence of the
                        whole word under or after the cursor.

                                                                  *+* *CTRL-M*
+ <C-M>                 Move [count] lines downward, to the first non-blank
                        character, linewise.

                                                                           *,*
,                       Repeat the latest f, t, F or T [count] times in the
                        opposite direction.

                                                                           *-*
-                       Move [count] lines up, on the first non-blank
                        character (linewise).

                                                                           *.*
.                       Repeat the last change, with [count] replacing the
                        original count.

                                                                           */*
/                       Search forward for the [count]'th occurrence of
                        {pattern}, entered on the command line.

                                                                           *0*
0                       Move to the first character of the line.

                                                                           *:*
:                       Start entering an Ex command. With [count] or from
                        Visual mode, a matching line range is filled in.

                                                                           *;*
;                       Repeat the latest f, t, F or T [count] times.

                                                                           *<*
<                       Shift the lines covered by {motion} one 'shiftwidth'
                        leftwards.

                                                               *<BS>* *CTRL-H*
<BS> <C-H>              Move [count] characters to the left. Wrap to the
                        previous line if 'whichwrap' contains b.

<BS> <C-H>              As an operator motion, move [count] characters to the
                        left. The end-of-line character is included when
                        wrapping via 'whichwrap'.

                                                               *CTRL-\_CTRL-N*
<C-\><C-N>              Go to Normal mode from any mode, abandoning any
                        pending command.

                                                                      *CTRL-]*
<C-]>                   Jump to the definition of the keyword under the cursor
                        using the IDE's Go to Declaration action, pushing the
                        position onto the tag stack.

                                                   *CTRL-^* *<C-S-6>* *CTRL-6*
<C-^> <C-S-6> <C-6>     Switch to the previously active editor tab (the
                        alternate file).

                                                                      *CTRL-A*
<C-A>                   Add [count] to the number or alphabetic character at
                        or after the cursor.

                                                           *CTRL-B* *<PageUp>*
<C-B> <PageUp>          Scroll the window [count] pages backwards (upwards) in
                        the buffer.

                                                                      *CTRL-D*
<C-D>                   Scroll the window [count] lines downwards (default:
                        half a screen), moving the cursor the same number of
                        lines. [count] sets 'scroll'.

                                                                    *<C-Down>*
<C-Down>                Run the IDE action bound to Ctrl+Down in the keymap,
                        such as moving to the next method.

                                                                      *CTRL-E*
<C-E>                   Scroll the window [count] lines downwards in the
                        buffer, revealing lines below the window.

                                                                     *<C-End>*
<C-End>                 Go to the end of line [count], default the last
                        character of the file.

                                             *CTRL-F* *<PageDown>* *<S-Enter>*
<C-F> <PageDown> <S-Enter>
                        Scroll the window [count] pages forwards (downwards)
                        in the buffer.

                                                                      *CTRL-G*
<C-G>                   Display the current file name, cursor position and
                        file status. With a [count], show the full path of the
                        file.

                                                              *CTRL-I* *<Tab>*
<C-I> <Tab>             Go to the [count]th newer position in the jump list.

                                                                      *CTRL-L*
<C-L>                   Clear and redraw the screen, also clearing the status
                        line.

                                                                      *CTRL-N*
<C-N>                   Move [count] lines downward, linewise. With a
                        completion popup open, select the next item instead.

                                                                      *CTRL-O*
<C-O>                   Go to the [count]th older position in the jump list.

                                                                      *CTRL-P*
<C-P>                   Move [count] lines up (linewise). With a completion
                        popup open, select the previous item in the popup
                        instead.

                                                             *CTRL-Q* *CTRL-V*
<C-q> <C-v>             Start blockwise Visual mode, or switch an active
                        Visual mode to blockwise; stop Visual mode if it is
                        already blockwise. Starts Select mode instead if
                        'selectmode' contains cmd.

                                                                      *CTRL-R*
<C-R>                   Redo [count] changes that were undone.

                                                                      *CTRL-T*
<C-T>                   Jump back to the [count]th older entry in the tag
                        stack.

                                                                      *CTRL-U*
<C-U>                   Scroll the window [count] lines upwards (default: half
                        a screen), moving the cursor the same number of lines.
                        [count] sets 'scroll'.

                                                                      *<C-Up>*
<C-Up>                  Run the IDE action bound to Ctrl+Up in the keymap,
                        such as moving to the previous method.

                                                                    *CTRL-W_+*
<C-W>+                  Increase the current window height by [count] rows.

                                                                    *CTRL-W_-*
<C-W>-                  Decrease the current window height by [count] rows.

                                                                 *CTRL-W_<lt>*
<C-W><lt>               Decrease the current window width by [count] columns.

                                                                    *CTRL-W_=*
<C-W>=                  Make all windows (almost) equally high and wide.

                                                                    *CTRL-W_>*
<C-W>>                  Increase the current window width by [count] columns.

                                                    *CTRL-W__* *CTRL-W_CTRL-_*
<C-W>_ <C-W><C-_>       Set the current window height to [count] rows; without
                        [count], make it as high as possible.

                                                         *CTRL-W_c* *CTRL-W_q*
<C-W>c <C-W>q           Close the current window (editor split).

                                    *CTRL-W_h* *CTRL-W_CTRL-H* *CTRL-W_<Left>*
<C-W>h <C-W><C-H> <C-W><Left>
                        Move to the window [count] windows to the left of the
                        current one.

                                    *CTRL-W_j* *CTRL-W_CTRL-J* *CTRL-W_<Down>*
<C-W>j <C-W><C-J> <C-W><Down>
                        Move to the window [count] windows below the current
                        one.

                                      *CTRL-W_k* *CTRL-W_CTRL-K* *CTRL-W_<Up>*
<C-W>k <C-W><C-K> <C-W><Up>
                        Move to the window [count] windows above the current
                        one.

                                   *CTRL-W_l* *CTRL-W_CTRL-L* *CTRL-W_<Right>*
<C-W>l <C-W><C-L> <C-W><Right>
                        Move to the window [count] windows to the right of the
                        current one.

                                                    *CTRL-W_o* *CTRL-W_CTRL-O*
<C-W>o <C-W><C-O>       Close all windows (editor splits) except the current
                        one.

                                         *CTRL-W_s* *CTRL-W_S* *CTRL-W_CTRL-S*
<C-W>s <C-W>S <C-W><C-S>
                        Split the current window in two, one above the other,
                        showing the same file.

                                                    *CTRL-W_v* *CTRL-W_CTRL-V*
<C-W>v <C-W><C-V>       Split the current window in two side by side, showing
                        the same file.

                                                                    *CTRL-W_W*
<C-W>W                  Move to the previous window, wrapping around. With
                        [count], go to window [count].

                                                    *CTRL-W_w* *CTRL-W_CTRL-W*
<C-W>w <C-W><C-W>       Move to the next window, wrapping around. With
                        [count], go to window [count].

                                                                  *CTRL-W_bar*
<C-W>|                  Set the current window width to [count] columns;
                        without [count], make it as wide as possible.

                                                                      *CTRL-X*
<C-X>                   Subtract [count] from the number or alphabetic
                        character at or after the cursor.

                                                                      *CTRL-Y*
<C-Y>                   Scroll the window [count] lines upwards in the buffer,
                        revealing lines above the window.

                                                                        *<CR>*
<CR>                    Move [count] lines downward, to the first non-blank
                        character. In a live template, jump to the next
                        template variable.

                                                                       *<Del>*
<Del>                   Delete the character under the cursor into register
                        [x].

                                                            *<Down>* *<kDown>*
<Down> <kDown>          Move [count] lines downward, linewise. Leaves Select
                        or Visual mode first if 'keymodel' contains "stopsel".

                                                                       *<End>*
<End>                   Move to the end of the line, [count] - 1 lines
                        downward. In Visual and Select mode, 'keymodel'
                        decides whether the selection is stopped.

                                                                      *<Home>*
<Home>                  Move to the first character of the line. In Visual and
                        Select mode, 'keymodel' decides whether the selection
                        is stopped.

                                                            *<Left>* *<kLeft>*
<Left> <kLeft>          Move [count] characters to the left. Wrap to the
                        previous line if 'whichwrap' contains <.

<Left> <kLeft>          As an operator motion, move [count] characters to the
                        left. The end-of-line character is included when
                        wrapping via 'whichwrap'.

                                                          *<Right>* *<kRight>*
<Right> <kRight>        Move [count] characters to the right. Wrap to the next
                        line if 'whichwrap' contains >.

<Right> <kRight>        As an operator motion, move [count] characters to the
                        right. The end-of-line character is included when
                        wrapping via 'whichwrap'.

                                                                    *<S-Down>*
<S-Down>                If 'keymodel' contains startsel (or continues the
                        current selection), start or extend a selection
                        [count] lines down. Otherwise scroll [count] pages
                        forward.

                                                                     *<S-End>*
<S-End>                 Move to the end of the line, [count] - 1 lines
                        downward. If 'keymodel' contains startsel, start or
                        extend a selection.

                                                                    *<S-Home>*
<S-Home>                Move to the first character of the line. If 'keymodel'
                        contains startsel, start or extend a selection.

                                                                    *<S-Left>*
<S-Left>                Move [count] words backward. If 'keymodel' contains
                        startsel, start or extend a selection [count]
                        characters to the left instead.

                                                                   *<S-Right>*
<S-Right>               Move [count] words forward. If 'keymodel' contains
                        startsel, start or extend a selection [count]
                        characters to the right instead.

                                                                      *<S-Up>*
<S-Up>                  If 'keymodel' contains startsel (or continues the
                        current selection), start or extend a selection
                        [count] lines up. Otherwise scroll [count] pages
                        backward.

                                                                     *<Space>*
<Space>                 Move [count] characters to the right. Wrap to the next
                        line if 'whichwrap' contains s.

<Space>                 As an operator motion, move [count] characters to the
                        right. The end-of-line character is included when
                        wrapping via 'whichwrap'.

                                                                *<Up>* *<kUp>*
<Up> <kUp>              Move [count] lines upward, linewise. Leaves Select or
                        Visual mode first if 'keymodel' contains "stopsel".

                                                                           *=*
=                       Re-indent the lines covered by {motion} using the
                        IDE's indentation rules.

                                                                           *>*
>                       Shift the lines covered by {motion} one 'shiftwidth'
                        rightwards.

                                                                           *?*
?                       Search backward for the [count]'th occurrence of
                        {pattern}, entered on the command line.

                                                                           *@*
@                       Execute the contents of register {register} [count]
                        times. @@ repeats the last executed register and @:
                        repeats the last command-line.

                                                                          *[(*
[(                      Go to the [count]'th previous unmatched '('.

                                                                          *[[*
[[                      Move [count] sections backward, or to the previous '{'
                        in the first column.

                                                                          *[]*
[]                      Move [count] sections backward, or to the previous '}'
                        in the first column.

                                                                          *[`*
[`                      Move to the [count]th previous lowercase mark.

                                                                          *[b*
[b                      Move backward to the start of the [count]'th previous
                        camelCase word part.

                                                                          *[M*
[M                      Go to the [count]'th previous end of a method.

                                                                          *[m*
[m                      Go to the [count]'th previous start of a method.

                                                                *[P* *]P* *[p*
[P ]P [p                Like P, but adjust the indent of the put text to the
                        current line.

                                                                          *[s*
[s                      Move to the [count]'th previous misspelled word before
                        the cursor.

                                                                          *[w*
[w                      Move forward to the start of the [count]'th next
                        camelCase word part.

                                                                          *[{*
[{                      Go to the [count]'th previous unmatched '{'.

                                                                          *])*
])                      Go to the [count]'th next unmatched ')'.

                                                                          *][*
][                      Move [count] sections forward, or to the next '}' in
                        the first column.

                                                                          *]]*
]]                      Move [count] sections forward, or to the next '{' in
                        the first column.

                                                                          *]`*
]`                      Move to the [count]th next lowercase mark.

                                                                          *]b*
]b                      Move backward to the end of the [count]'th previous
                        camelCase word part.

                                                                          *]M*
]M                      Go to the [count]'th next end of a method.

                                                                          *]m*
]m                      Go to the [count]'th next start of a method.

                                                                          *]p*
]p                      Like p, but adjust the indent of the put text to the
                        current line.

                                                                          *]s*
]s                      Move to the [count]'th next misspelled word after the
                        cursor.

                                                                          *]w*
]w                      Move forward to the end of the [count]'th next
                        camelCase word part.

                                                                          *]}*
]}                      Go to the [count]'th next unmatched '}'.

                                                                           *^*
^                       Move to the first non-blank character of the line.

                                                                           *_*
_                       Move [count] - 1 lines downward, to the first
                        non-blank character, linewise.

                                                                           *`*
`                       Jump to the exact position (line and column) of mark
                        {mark}.

                                                                           *A*
A                       Append text at the end of the line [count] times.

                                                                           *a*
a                       Append text after the cursor [count] times.

                                                                          *a"*
a"                      A double-quoted string: select the quoted text,
                        including the quotes and trailing white space.

                                                                          *a'*
a'                      A single-quoted string: select the quoted text,
                        including the quotes and trailing white space.

                                                                     *a<* *a>*
a< a>                   A <> block: select [count] <> blocks, including the
                        angle brackets.

                                                                     *a[* *a]*
a[ a]                   A [] block: select [count] [] blocks, including the
                        brackets.

                                                                          *a`*
a`                      A backtick string: select the text between backticks,
                        including the quotes and trailing white space.

                                                                *aB* *a{* *a}*
aB a{ a}                A Block: select [count] {} blocks, including the
                        braces.

                                                                *ab* *a(* *a)*
ab a( a)                A block: select [count] () blocks, including the
                        parentheses.

                                                                          *ap*
ap                      A paragraph: select [count] paragraphs, including the
                        following blank lines.

                                                                          *as*
as                      A sentence: select [count] sentences, including
                        trailing white space.

                                                                          *at*
at                      A tag block: select [count] XML/HTML tag blocks,
                        including the tags.

                                                                          *aW*
aW                      A WORD: select [count] WORDs, including trailing white
                        space.

                                                                          *aw*
aw                      A word: select [count] words, including trailing white
                        space.

                                                                *B* *<C-Left>*
B <C-Left>              Move [count] WORDS backward.

                                                                           *b*
b                       Move [count] words backward.

                                                                           *C*
C                       Delete till the end of the line and [count]-1 more
                        lines into register [x], then start Insert mode.

                                                                           *c*
c                       Delete the text moved over by {motion} into register
                        [x] and start Insert mode.

                                                                           *D*
D                       Delete from the cursor to the end of the line and
                        [count]-1 more lines into register [x].

                                                                           *d*
d                       Delete the text moved over by {motion} into register
                        [x].

                                                                           *E*
E                       Move forward to the end of the [count]'th WORD.

                                                                           *e*
e                       Move forward to the end of the [count]'th word.

                                                                           *F*
F                       Move to the [count]th occurrence of {char} to the
                        left.

                                                                           *f*
f                       Move to the [count]th occurrence of {char} to the
                        right.

                                                                           *G*
G                       Go to line [count], default the last line. The cursor
                        goes to the first non-blank character unless
                        'startofline' is off.

                                                                          *g#*
g#                      Like #, but also match the word under the cursor when
                        it is part of a longer word.

                                                                 *g$* *g<End>*
g$ g<End>               Move to the last character of the screen line. Differs
