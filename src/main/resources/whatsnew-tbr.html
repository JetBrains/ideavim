command line · cmdline-window

Edit long commands with Vim motions

Press <C-F> while typing an Ex command or a / or ? search to open the command-line window. What you've typed so far becomes its last line, so a long command or pattern can be fixed up with ordinary Normal mode motions. Press <CR> on any line to run it.

:%s/someLongIdentifier/other<C-F>   " open the command-line window
bcwnewName<Esc>                      " edit it like any other text
<CR>                                " run the line under the caret

new plugin · git

:Ggrep and the quickfix list

The bundled fugitive extension emulates the :Ggrep command of vim-fugitive. It runs git grep, so only the files tracked by Git are searched, and jumps to the first match. Every match goes to the quickfix list, which you can walk through or show in its own window.

Plug 'tpope/vim-fugitive'

:Ggrep foo              " search tracked files, jump to the first match
:Ggrep! foo             " collect the matches without jumping
:cnext / :cprevious     " walk through the matches
:cnfile / :cpfile       " ... or file by file
:copen                  " show them all, <CR> jumps to one

:cfirst, :clast and :cclose work too.

ex commands · actions

Search and run actions from :actionlist

:actionlist now opens in a read-only buffer, like :help and the quickfix list, instead of a pager. Search it with /, move around with your usual motions, and press <CR> on a line to run that action in the editor you opened the list from.

:actionlist Goto      " list the actions whose ID matches
/Declaration<CR>      " search the list
<CR>                  " run the action on the current line

clipboard · x11

Control what reaches the PRIMARY selection

The 'clipboard' option now supports the autoselect flag. It is on by default, so Visual and mouse selections are copied to the X11 PRIMARY selection (the * register). Turn it off if you'd rather keep PRIMARY to yourself.

set clipboard-=autoselect   " don't copy selections to PRIMARY

also worth a look

CTRL-T after Ctrl+Click

Ctrl+Click, Go to Type Declaration, Go to Implementation and mappings such as nmap gi <Action>(GotoImplementation) now push onto the tag stack, so CTRL-T brings you back.

<C-O> back into diffs

Jumps made in a diff tab now bring back the diff, on the same side, instead of the plain file, even after Go to Declaration.

Surround in :normal

:normal yss" works, :1,3normal yss<b> wraps each line, and S in Visual block mode surrounds every line of the block.

Smoother scrolling

Scrolling now handles soft wraps, block inlays and notebook outputs properly, and CTRL-E/CTRL-Y step through tall inlays one row at a time.

polish & fixes

  • No freezes while typing — typing in large projects no longer freezes the UI.
  • Undo in remote development — in Rider and CLion, u undoes one command at a time, works right after leaving Insert mode, and the first edit in a document is no longer lost.
  • Esc in Rider completion — it leaves Insert mode in remote development even when the popup shows a type or overloads, and sethandler <Esc> i:ide only closes the popup, as configured.
  • Pasting from other apps on X11 — p from the + register no longer pastes nothing the first time.
  • Blockwise "+y — on systems without PRIMARY it is pasted blockwise again.
  • ideaput keeps your clipboard — in remote development, p no longer replaces what another application copied.
  • Sticky lines and 'scrolloff' — moving left and right no longer makes the editor scroll back and forth.
  • cc and S in C# — Rider now indents the emptied line.
  • New lines in the AI chat — o, O, <C-J>, <C-M> and mappings ending in <CR> break the line in the prompt.
  • Literal carriage return — <C-V><CR> in Insert mode no longer raises an error.
  • Prompts that aren't searches — 'incsearch' no longer moves the caret while you type a surround tag name or a <C-R>= expression.
  • Turning IdeaVim off — extensions such as NERDTree stop handling keys in the Project tool window.
  • Closing tabs from actions — no more "Editor is already disposed" errors after an action closes the editor.
  • Mode widget — no opaque rectangle on the status bar when a terminal or agent tab is selected.
